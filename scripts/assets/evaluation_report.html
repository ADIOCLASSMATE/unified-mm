解码策略 · 固定 B 与采样参数

这里的 sigma 指位置的揭示顺序。所有策略固定 CFG=2.0、Heun=10，在相同的 ImageNet-val 50K、seed 42 和逐位置噪声上比较。真实图像与训练时的 sigma 排列不参与顺序选择。

各解码策略的定义与探测协议

Halton 保持空间分散；sequential 逐行扫描；spatial_uniform 是现有的中心向外顺序；random 为每张图抽取随机排列。

三个新方法每次对接下来的 16 个 Halton 位置评分，利用已生成内容，在组内决定后续顺序。CFG agreement 先选条件与无条件速度预测相近的位置；CFG reverse 反向选择；velocity stability 先选一次 Δt=0.1 的 Euler 探测前后，引导速度变化较小的位置。所有候选最终都从原始噪声重新生成。probe control 执行相同探测并保留 Halton 顺序，用来检查探测开销和数值影响。

这两个分数是为连续 latent 设计的启发式指标，尚未校准为置信概率。MaskGIT 的高置信优先提供了思路；本实验没有离散 token 的预测概率，因此用速度一致性作可检验的替代。

跨模型采样与换序 · 9 个模型

9 个正式模型，各使用自己的 step-95415 final EMA、注意力与 flow 条件。每组 16 卡生成 ImageNet-val 50K，固定 seed 42、逐位置初始噪声、BF16 模型和 FP32 VAE。IS 的 ± 为十个按类别分层 split 的标准差。

同一配置下比较生成顺序 · 方法与协议

全部模型比较 spatial_halton、confidence_stability 与 random。Stability 在接下来的 16 个 Halton 位置中，优先生成一次 Δt=0.1 探测前后引导速度变化较小的位置。探测只读取已生成内容；候选最终都从原始噪声重新解码。Random 对全部 256 个位置取均匀随机排列，固定评测种子与批次划分，不进行候选探测。

A 保留严格注意力；旧模型保留 shared-query 条件；D 的两次探测均重新计算当前 XT 条件；F 继续使用无跨 token 内容流的逐位置 flow head。E 额外保留 CFG=2.0 的 sequential 对照，以区分 CFG 变化和换序的影响。CFG=2.0 来自 B 的选优，尚未对每个模型分别调参。

Loss 计算口径、验证覆盖与缺失项说明

T2I、I2T 和纯文本分别读取 loss_t2i、loss_i2t、loss_climbmix 的 train/ 与 val/ 字段。历史 val/loss_text 是 I2T caption CE，train/loss_text 混合了两种文本任务，均不能代替纯文本验证 loss。

新协议与训练统一：验证三个活跃任务，使用当前训练权重和相同前向处理、任务开关及随机损失机制，在 no_grad 下计算。各任务原始 loss 按有效目标数平均；总 loss 则对各任务的 model.loss 取 microbatch 均值，再乘该任务在梯度累积调度中的比例。默认调度为 ClimbMix → T2I → ClimbMix → I2T，因此三项贡献分别为 1/2、1/4、1/4 乘各自已加权的 microbatch 均值。单任务实验的贡献比例为 1。具体协议见 训练与验证统一 loss。

历史记录保持原口径：旧 ImageNet 验证总 loss 为 λ_image × T2I + λ_text × I2T，不含纯文本与训练调度比例；不能通过相减补出纯文本验证，也不能直接与训练总 loss 比较。旧记录与新记录分别标注，协议切换处断开，可用“验证协议”筛选。训练与验证使用不同数据，caption 来源见“数据与协议”。

新协议的 T2I / I2T 验证直接复用轻量分类评测的同一份 ImageNet-val 清单，默认每类 2 张、共 2,000 张；纯文本沿用 400 条固定源记录。先固定全局 microbatch 分组，再按 rank 分配；不补齐、不重复，随机损失按固定全局 batch seed 计算。历史验证通常只遍历前若干 batch；缺失任务保持空白。这里只汇入训练期间验证；独立最终 EMA 评测见“模型评测”，下游准确率仍使用独立评分协议。

纯文本默认固定 400 条 ClimbMix 记录。只有从训练开始启用行排除的实验才算按源记录留出；否则标为“可能见过训练文本”。已完成训练无法事后获得同一历史时刻的独立验证 loss。具体数据划分及启用方式见 纯文本验证协议。
