## 固定数据

样本清单和采集协议先于本轮新特征得分保存，种子 20260909，路径为指定 run 下 `representation-diagnostic/geometry-v4-20260907`。

### ImageNet

- 1000 类，每类 32 张图，共 32000 图；排除 V1 的 10000 张与 V2 的 8000 张图像身份。
- 每类分为 2 cal、15 a、15 b；a/b 不重叠。每类 12 个文本模板，分为 4 cal、4 a、4 b。
- 类别隔离为 600 fit、200 dev、200 test。校准仅用 fit 类别的 cal 图/模板。
- 主分析：fit/dev/test 类别均用 a 视图、a 模板，避免把类别外推与模板变化混为一个主指标。b 图像是重复参考，b 文本是独立措辞敏感性检查。
- 原型图像数固定为 1/3/5/10/15，使用预先随机排列的嵌套前缀。先平均原始特征，再做分析预处理。
- “新类别”仅针对拟合映射，B 本身训练已使用这些 ImageNet 类别；旧模板也可能重用，不作新词面声明。

### COCO

从本地 Karpathy 标注的 train 划分选出 **11776 个独立场景**，排除整个旧检索 test 池及 V2 使用的 SugarCrepe 图像：512 cal、8192 fit、1024 dev、2048 test。共有 58909 条 caption；一个场景的全部 caption 始终在同一数据划分。

图片从公开 COCO S3 路径下载，保持 TLS 验证，逐文件进行 PIL 解码校验；复用项目 MAR KL16 编码器，FP16 posterior mean/std、scaling factor 0.2325，明确 `--no_hash`。数据均写共享盘，不覆盖旧 benchmark 缓存。

主语义单位为一张图对其全部 caption 特征的平均。另外比较前 1/3/5 条 caption，以及前 2 条对剩余 caption 的同场景重复参考。拟合规模在固定 fit 池内取 512、2048、8192，测试池不变。

COCO 是相对本次 B 的 ImageNet 图像训练的域外数据；不宣称排除了 LM/VAE 全部预训练数据。它不是本模型训练过 COCO 的“域内训练集”，Karpathy train 只是数据来源的划分名。

### ARO

从已有 Visual Genome 缓存固定选取 1000 个关系样本、1000 个属性绑定样本，2000 个原图身份互不重复。每个样本比较正确 caption 与控制负例，不在 ARO 上拟合任何映射。

使用 COCO 学到的映射进行迁移，和原始坐标、打乱拟合、打乱图像等对照比较。该部分是新几何/功能诊断，不宣称原 benchmark 从未被评估，也不对图像内容做哈希去重。

## 分析与可解释性约束

- 主欧氏模式只减模态校准均值；单位球模式额外逐语义单位 L2 归一化，分开解释。
- RSA 比较非对角欧氏距离的排序；线性 CKA 比较中心化 Gram；kNN@5/10/20 比较内部近邻身份，排除自己。使用语义身份置换，不能打乱距离矩阵的独立元素。
- 旋转只用 fit 数据估计中心、独立 PCA、全局 RMS 单位和正交 Q；不逐轴白化。额外报告一个拟合的整体尺度，不把全局尺度与任意拉伸混同。
- R²=1−NRMSE²，基线为预测拟合均值，允许负数。报告原型/场景泛化误差与对照差值，不用单独的训练拟合分数判断同构。
- 报告数值秩、有效维度、条件数、PCA 方差保留；样本数大于 1024 不自动意味着所有语义方向都可稳定识别。
- 用 dev 选择设置；固定最终层及完整层曲线始终保留。置信区间按语义组抽样，不把同图多个 caption 当独立样本。
- 跨数据集时冻结源域的全部分析参数，不在目标域重新中心化/PCA/拟合。功能负例检验避免把 CKA 高分直接叫做语义成功。
- 顺序/后验子集：COCO 全部 cal + 固定 512 test 场景；ImageNet 固定 32 个 test 类别。以主 native 拟合参数检验这些扰动，不用测试类别重新拟合对齐参数。

## 事后解释性补充：query 空间位置（17:03 UTC）

在查看预先固定的 sigma 稳定性结果后，核对到文本条件下首图像 query 的 0-based 槽位：native `(7,8)`、sigma1 `(7,7)`、sigma2 `(14,13)`。因此此扰动不是固定位置的纯顺序干预：图像 Content 侧改变 sigma 可见次序，文本条件的首目标 query 侧还改变了空间读出位置。不能把变化全部归因于语义或顺序。

新增 CPU-only 解释性诊断，明确属于事后探索：固定 final RMSNorm、Content mean 和 native query，使用已有 512 个独立 COCO cal 场景估计位置变化的模态均值偏移；在固定 512 test 场景上测试单独去除该偏移能恢复多少。已有 8192-fit 图文映射始终不重新拟合。同时比较同模态内部几何、各自校准后的坐标余弦，以及 512-cal 拟合的同模态 full/32-D 正交映射。512-cal 的 full 1024-D 映射仍然样本不可识别，不作为全空间旋转的确认。

该补充不替换主分析的严格冻结均值结果，也不算作无需目标适配的成功；目的是区分整体平移、几何变化和位置相关的生成读出。

## 身份审计补充：COCO / Visual Genome 原图重合（17:09 UTC）

采集清单保证 ARO 内部的 2000 张 VG 原图互斥，但数据集名不同不保证与 COCO 池互斥。追加作者维护的 [VG 图像元数据](https://homes.cs.washington.edu/~ranjay/visualgenome/api_readme.html) 身份对照，发现 76 张与 V4 COCO cal/fit/dev/test 某部分重合，1056 张未提供可核对的 COCO ID，868 张具有明确 COCO ID 且不在 V4 全部 COCO 池中。

原先 2000 样本的全部层结果照常保留，但不称为严格原图隔离迁移。追加固定 final RMSNorm、全部七个状态/提示组合、三种读出、两种几何和四个维度的 ARO 检验：分别报告 **868 张已核对互斥原图**与 **1924 张排除已知重合原图**。后一个子集仍有无法确认的身份链接，不能用“未查出重合”代替“确认互斥”。这两个子集均按身份规则确定，不按模型得分删选，不在 ARO 上拟合映射；图像置换和 bootstrap 在各自子集的任务内重新执行。
