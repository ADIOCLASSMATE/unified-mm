# 跨模型语义几何 V5

日期：2026-09-07。目标是在冻结模型条件下完成 B/F、JanusFlow-1.3B、
Show-o2-1.5B、SigLIP-so400m-patch14-384、DINOv2 ViT-B/14 + 原始
Qwen3-0.6B-Base、MAE ViT-B/16 + 原始 Qwen3-0.6B-Base 的同协议比较。
本协议承接 [V4](B_GEOMETRY_PROTOCOL_V4.md)，不是训练实验。最初冻结时
尚未观察任何新增模型几何得分；适配器仅允许在 cal 数据上验证前向、掩码和数值。

## 不可缩减的完成要求

1. 七个比较设置全部有可验证的来源、完整所需特征及同协议结果；B 可复用
   已审计 V4 缓存，F 必须加载 F 的模型类与最终 EMA，不用 B 类冒充。
2. 完整复用 ImageNet 32000 图 / 12000 模板、COCO 11776 场景 / 全部
   58909 caption；ARO 主结果只使用 V4 身份审计确认互斥的 868 张原图及
   1736 条候选文本。不能把多个 caption 当独立测试图像。
3. 各侧采集输入、每个 backbone block 及最终规范化表示。共同的内容池化
   与原生任务读出分表；不存在的 query 不补零冒充实际语义读出。
4. JanusFlow 和 Show-o2 分开理解与生成路径；记录视觉编码器/融合后的输入
   表示，防止把既有语义教师的能力归给共享 backbone。生成相关探针必须
   标明图像/文本条件、时间、噪声种子和读取位置，并有噪声敏感性补充。
5. 全层 kNN@5/10/20、RSA、线性 CKA；fit-only 正交 Procrustes，32/128/512
   维为共同预算，full 仅作各模型自身诊断。双模态原始维度不同不能直接
   声称全空间正交同构。报告 PCA 方差保留、样本秩与跨协方差条件数。
6. ImageNet / COCO 两个源域的 held-out 与全参数冻结跨域迁移；COCO
   512/2048/8192 拟合规模曲线；严格 ARO 配对负例功能测试。保持负 R²、
   配对打乱及图像打乱对照，不只保留正结果。
7. 固定最终层与开发集选择分别报告。按语义组做测试 bootstrap 和模型间
   配对差值；不得看 test 或 ARO 选层、维度、时间、提示或池化。
8. 完整性/泄漏/数值审计、单元测试、图表、中文报告及逐项完成审计；最终
   停止本轮启动的 dev-wjx-ascend，保留 Notebook 对象和全部产物。

## 数据与几何口径

原始身份及顺序来自 V4 的 samples.json，种子沿用 20260909。ImageNet
600 fit / 200 dev / 200 test 类别、每类 cal/a/b 视图不变；主原型 a15，
独立 b15 与模板 b 为可靠性/措辞参考。COCO 512 cal / 8192 fit / 1024 dev /
2048 test 不变。同场景先平均原始 caption 特征，再进行中心化/球面化。

欧氏与单位球两种分析分开解释；只允许中心、独立 PCA、每侧整体 RMS
单位换算和正交旋转/反射，不逐轴白化。跨数据集不重新估计任何这些参数。
几何邻居集合保持 ImageNet 200 测试类、COCO 前 512 测试场景；映射误差
使用全部 2048 COCO 测试场景。随机对照沿层共享身份置换，并保留层搜索零分布。

图像必须来自相同原图/ARO 裁剪；各模型使用声明的输入分辨率和归一化。
不同 VAE 缓存不混用。实际裁剪、缩放与 tokenizer 截断规则必须写入适配器
契约，并在正式采集前冻结。所有真实目标内容都不可进入相对的单模态输入。

## 读出与路径约束

- B/F：native、bare、neutral 保持 V4 的 X0/XT 可见性、三种池化和首 query。
  F 使用独立配置加载；B 复用结果前重新检查样本/协议/文件身份。
- SigLIP：图像与文本各自独立前向；逐层内容均值与原生最终输出分开。
  正式输出中的池化/投影是训练好的表示组件，不能混同于 backbone 内容均值。
- DINOv2/MAE：视觉与 Qwen 独立，没有重新训练图文连接器。MAE 使用未经
  分类微调的权重；主推理保留全部 patch，不能忘记默认随机 mask。
- 不同 encoder 深度不强行匹配同一个层号。原始所有层保存，比较层对采用
  预先声明的相对深度匹配，实际两侧层号都进入机器结果。
- JanusFlow/Show-o2：共同内容读出不依赖特有 query；原生生成槽位读出另列。
  理解编码路径与 clean-image 生成编码路径分开。文本生成槽位仅可使用
  与样本语义无关的固定初始噪声；含配对真图的 teacher-forced 混合输入不
  能作为文本 embedding。时间/噪声扩展只在预先固定 cal/test 鲁棒子集实施，
  不能用这些 test 得分选主设置。

适配器确切序列、层列表、池化和读取位置在 cal-only smoke 后保存为
adapter-contracts/*.json，先于正式特征得分。若技术修复改变语义契约，创建
新版本并重提对应特征，不覆盖已计分版本。

## 解释边界与来源

- B/F：Qwen 与 MAR VAE 预训练 + 配对生成训练；没有本次新训练。
- JanusFlow：预训练 SigLIP 理解编码器，并用 REPA 对齐生成侧的中间表示，
  不是仅有生成目标的无教师模型：[原论文](https://arxiv.org/html/2411.07975v1)。
- Show-o2：VAE 语义路径先接受 SigLIP 蒸馏，再与低层路径融合进入 LLM；
  LM head / flow head 使用自回归 / flow matching：
  [原论文](https://arxiv.org/html/2506.15564v2)。
- SigLIP 是显式图文对齐正对照；DINOv2 + Qwen 是独立单模态结构对应参考；
  MAE + Qwen 的视觉侧重建预训练另作参考。三者不是负对照意义的纯随机模型。

外部模型的参数、训练数据、预算、初始化及指令微调不同，分数排名不能直接
归因为架构。F 的 backbone 架构与 B 一样，但分别训练、权重不相同。它移除
flow head 跨 token 交互，不等于移除 head 一切语义计算。

## 校准期数值修订（修订前未查看对应模型的语义得分）

SigLIP 的 32 个 ImageNet cal 图像中，rank 5 的 BF16 批量/单样本校验
失败。相同输入像素完全一致，但一个逐层读出的余弦低至 0.94839；原生最终
pooler 的余弦仍为 0.99995，说明只检查最终对齐输出不足以保证中间层稳定。
重新从原始权重以 FP32 加载后，相同 cal 检查最低逐层余弦为 0.99999994。
因此 SigLIP 正式计算使用 FP32，池化后仍按共同 BF16 格式储存；旧 BF16
cal 分片和契约归档，不混入正式比较。此决定只基于 cal 数值一致性，未使用
test 语义得分。B/F 和其余适配器的精度及来源按各自冻结契约报告。

JanusFlow 的 16 卡 cal 检查亦在 rank 1 的理解路径发现批量敏感性：
原始 BF16 中最低逐层余弦 0.97835，而上游视觉编码均值余弦约 0.99998。
FP32 算术下最低逐层余弦恢复到 0.99999952；正式 JanusFlow 因此也使用
FP32。其 BF16 cal 产物同样归档。本次调整不改变权重、注意力或语义输入。

Show-o2 在其语义得分计算前的全层 cal 复核发现 BF16 最差余弦 0.935019。
正式修订采用 FP32 算术、FP32 存储及对所选 token 直接计算输入均值，
消除 padding 对固定噪声输入的舍入影响；其数学池化含义不变。最终 cal
最差余弦 0.99998772。旧完整 BF16 特征与契约归档，重提全部主设置和
噪声控制；仅 Show-o2 契约版本变化，其他 12 个设置逐字段不变。
详见方法文档的精度修订和数值警告，以及机器可读 revision 审计。
