# 跨模型语义几何 V5：方法与解释边界

这是结果报告的方法配套文档，不是实验完成声明。任务范围由
[V5 协议](CROSS_MODEL_GEOMETRY_PROTOCOL_V5.md)与
[V4 基准协议](B_GEOMETRY_PROTOCOL_V4.md)确定，完整结果与资源收尾另行验收。

## 要检验什么

“图文向量接近”与“图文关系结构对应”是两件事。后者允许模态拥有不同
坐标系，甚至不同原始宽度。我们从弱到强分别检验：

1. 同一批语义身份在两侧的邻居是否重合、距离排序是否对应；
2. 各自仅用 fit 数据提取的低维子空间，能否通过正交旋转／反射对应；
3. 这种对应能否外推到未参与拟合的类别／场景，并冻结全部参数跨数据集迁移；
4. 迁移后的图像表示能否分辨属性绑定和关系负例，而不只是捕捉大类主题。

这与“不同模型可能学习相关关系结构”的研究方向相连，但不预设所有模型
收敛到同一空间。关系相似性不能单独证明信息相同、计算机制相同或头部只
负责采样。[Platonic Representation Hypothesis](https://proceedings.mlr.press/v235/huh24a.html)
提供了相关动机；[CKA 原论文](https://proceedings.mlr.press/v97/kornblith19a.html)
解释了表示比较对坐标变换的要求。

## 数据和输入

ImageNet 使用 V4 的 1000 类、32000 张验证图像、12000 条模板，映射类别
隔离为 600 fit／200 dev／200 test。每类两个 cal 图像、独立 a15／b15
图像和三组各四个模板。主比较使用 a15／a 模板；图像数和独立措辞为敏感性
参考。这里的“未见类别”仅针对拟合的映射，不针对 B/F 的 ImageNet 训练。

COCO 使用 11776 个独立场景：512 cal、8192 fit、1024 dev、2048 test；
保留全部 58909 条 caption。先平均同场景的原始文本特征，再做中心化或
L2 归一化，不把多个 caption 当作独立测试样本。几何图使用固定前 512 个
测试场景；映射误差使用全部 2048 个测试场景。

ARO 使用 V4 身份审计确认 COCO ID 不在上述任何 COCO 划分中的 868 张
原图，保留官方裁剪和成对正确／错误文本，不在 ARO 拟合或选择参数。
这不是图像内容去重或全部预训练语料去污染证明。ARO 的设计针对组合语义
的薄弱环节，不能用较高 CKA 替代这个功能测试。
[ARO 原论文](https://arxiv.org/abs/2210.01936)

外部视觉模型先读取与 B 缓存一致的 RGB 内容视图：短边 bicubic 缩放至
256，再中心裁剪 256；随后缩放到各模型输入分辨率并应用原生归一化。
因此这是共同内容视图比较，不是各模型最优原生高分辨率推理的排行榜。
不同模型使用自己的 VAE，不混用 latent 缓存。MAE 保留全部 patch，且固定
patch 顺序；Qwen 使用原始 Base 权重，不使用 B 的初始化参考缓存冒充。

## 模型的语义来源并不相同

| 模型／路径 | 已有语义来源与训练区别 | 本实验中的角色 |
| --- | --- | --- |
| B | Qwen3 Base、MAR VAE 初始化；ClimbMix 加配对 ImageNet 合成描述的双向条件生成，CE 权重 0.05、flow 权重 1 | 待检验模型；不是从零、无配对的“纯压缩” |
| F | 与 B 同一 backbone 架构和训练合同，独立训练最终 EMA；参数匹配的逐位置 MLP flow head | 更接近架构对照；不等于与 B 共享 backbone 权重 |
| JanusFlow | 预训练语言模型、SigLIP 理解编码器、SDXL VAE；AR、rectified flow 加 REPA，并有 SFT | 理解／生成路径分别比较，不能称无教师生成基线 |
| Show-o2 | Qwen2.5-Instruct、Wan VAE；VAE 语义路径预先接受 SigLIP 蒸馏，再进行 AR／flow 与指令训练 | 语义路径、低层路径和融合输入均有记录 |
| SigLIP | 显式图文 sigmoid 对齐目标 | 对齐正对照；训练过的最终 pooler 与 backbone 内容均值分开 |
| DINOv2 + Qwen | 两个独立单模态模型；DINOv2 自监督且小模型包含教师蒸馏 | 无新图文连接器的关系结构参考，不是随机负对照 |
| MAE + Qwen | 视觉侧 masked-pixel reconstruction；文本侧原始语言预训练 | 重建式视觉预训练参考，不是联合图文纯重建实验 |

JanusFlow 的 REPA 将生成任务中 LLM 的中间表示对齐到理解视觉编码器；
它不是仅在最终采样头上施加生成误差。
[JanusFlow 原论文 §3](https://arxiv.org/html/2411.07975v1)

Show-o2 将语义分支和低层分支融合后送入 LLM，语义分支接受 SigLIP 蒸馏；
所用 1.5B 名称指语言模型规模，不是整个统一模型的参数量。本实验使用
基础 1.5B 权重，不混入 HQ、7B 或后续视频增强版本。
[Show-o2 原论文 §3–4](https://arxiv.org/html/2506.15564v2)

SigLIP 的显式成对对齐目标见
[原论文](https://arxiv.org/abs/2303.15343)；DINOv2 的自监督和蒸馏区别见
[原论文](https://arxiv.org/abs/2304.07193)；MAE 的重建式预训练见
[原论文](https://arxiv.org/abs/2111.06377)。Qwen3-0.6B-Base 是 28 层、
预训练阶段的 causal LM，不能把其指令微调版本与 Base 混用。
[Qwen 官方模型卡](https://huggingface.co/Qwen/Qwen3-0.6B-Base)

## 层、读出与坐标变换

保存输入位置、每个实际 block 输出及最终归一化。不同深度编码器使用预先
冻结的相对深度网格，并同时记录真实两侧层号，不按测试成绩寻找最佳层对。
共同内容均值、内容末 token 与原生任务位置分开。CLS、EOS、assistant
boundary、B/F query 与生成槽位承担不同作用，不能仅因表格同列就当作相同
读出。SigLIP 的训练后 pooler 单列，不冒充某个 backbone block。

欧氏模式先减模态校准均值；单位球模式还逐语义单位 L2 归一化。欧氏距离
对平移本身不敏感，线性 CKA 又会中心化 Gram，因此减均值不会自动改变
这些欧氏关系指标；单位球化则确实改变几何，必须分开解释。

每侧独立 PCA、fit 均值和整体 RMS 单位都只来自源域 fit 数据。主映射是
正交 Q，不逐轴白化、不使用一般线性拉伸；另报一个整体拟合尺度作为补充。
32／128／512 维是共同预算，full 只作模型自身诊断。原始维度不同时，不存在
这里所说的全空间方阵旋转；低维成功也不代表丢弃方向没有语义。

R² = 1 − 总平方误差／相对源域拟合目标均值的总平方变化，允许负数。
同时报告 shuffled-fit、PCA 方差保留、每侧数值秩和跨协方差条件数。
V5 的 rotation_identified 还要求跨协方差在相对阈值 1e-6 下满秩；仅样本
数量大于宽度、或两侧各自满秩，均不足以保证旋转可识别。

## 生成路径不是混合输入的捷径

JanusFlow／Show-o2 图像条件使用真实图像的 VAE 后验均值、t=1、空文本
条件；文本条件只使用观察文本和与语义身份无关的固定初始高斯噪声、t=0。
绝不把配对真图放进“文本 embedding”的输入。主探针读取 backbone 的内容
或生成槽位，不执行完整 ODE 采样，因此不是生成质量测评。

两个额外固定噪声种子和图像 t=0.5 的插值，在 V4 预定的 32 个 ImageNet
测试类／512 个 COCO 测试场景上检查。中间时刻只改变图像条件，文本复用
未扰动主表示。源域的均值、PCA、RMS 和 Q 全部冻结。

B/F 的 sigma 变化同时改变原生首图像 query 的空间位置，不能叫作纯顺序
干预。它与 VAE 后验均值对照均保留严格冻结映射结果，不靠重新中心化恢复
后的成绩替换主结果。

## 统计与审计

全层 RSA、CKA、kNN 使用 199 次语义身份置换，各层共享置换；同时保存每条
预定曲线的层搜索零分布。dev 在每个预定读出、模式、拟合规模中选择层和
共同子空间维度，不能用 test、跨域或 ARO 选设置。固定最终层一直保留。

映射与 ARO 使用 2000 次身份级 bootstrap；模型差值使用相同身份抽样。
kNN 区间固定候选图、重采样 query 身份，不宣称覆盖候选集合变化的不确定性。
这些是给定训练权重、fit/PCA 和 dev 选择的条件区间，不是新训练种子重复，
也不是全实验多重比较的同时置信区间。不同模型的 R² 各有自己的表示空间
分母，差值不表示在同一个原始重建目标上的误差差。

所有权重冻结；下载固定官方 revision、显式禁用代理，依赖隔离安装到
public/models。来源核验逐参数比较实际值，另做样本、分片、目标替换、
数值、分析覆盖与统计重算审计，不计算权重或数据哈希。

## 记录勘误（不改变实际前向）

JanusFlow 的冻结契约中 generation_noise 文本仍写了“cast BF16”，这是
校准期升为 FP32 后遗留的描述。实际 `FlowAdapter.noise` 一直转换到
`self.dtype`：本次 JanusFlow 为 FP32；Show-o2 初版为 BF16，校准复核后
正式修订为 FP32，且新契约已改正描述。基础随机数均在
CPU 以 FP32 生成。原始契约和特征不改写，按实际代码与精度字段解释。

Show-o2 的载入参数逐名称求和为 3,063,740,640，但源权重中的语言 embedding
和 lm_head 共享同一存储。去除这一重复后为 2,830,777,056 个独立存储元素，
不含另载入的 Wan VAE。不能将逐名称求和误当成不同的已训练自由参数。

## Show-o2 校准期精度修订与局部数值警告

在尚未计算 Show-o2 语义得分时，32 个 cal 行、全部层和池化的单样本／
正式 batch=8 对照发现 BF16 最低余弦 0.935019。改用 FP32 算术后图像
路径恢复，但 BF16 存储会抹去早期生成槽位的微弱语义变化。因此正式
Show-o2 使用 FP32 算术和 FP32 池化特征存储；其余模型保持原冻结精度。
固定噪声的输入槽位还存在 padding 长度引起的 BMM 舍入差异，输入位置
改为对所选 token 直接做 FP32 均值，其数学读出和语义输入未变。

修订后的 cal 检查最低逐层余弦为 0.99998772。批量误差相对中心化语义
信号的 RMS：图像路径最高约 0.00205，COCO 文本最高约 0.00373；
ImageNet 文本的首 block 单点生成槽位仍为 0.03768，应谨慎解释极弱的
早期槽位信号。完全相同的输入噪声不应被当成语义差异。

旧 BF16 cal、完整特征、视图、契约和日志全部保存在
`calibration-archive/showo2-fp32-cal-revision-2/`，没有删除或覆盖。
比较契约修订仅允许 Show-o2 的精度、存储和数值等价的输入池化字段改变；
其余 12 个设置逐字段保持相同。修订不使用测试、迁移或 ARO 成绩。

B/F 的主 native 内容均值校准检查稳定；neutral 的末 token 存在局部
BF16 批量敏感性（B 最低约 0.99177，F 约 0.95020）。保留与 V4 一致
的完整敏感性曲线，但不依据这一局部读出提出强架构优劣结论。

最终结论必须同时考虑关系结构、留出／跨域映射、负例功能、方差覆盖和
扰动稳定性。即使 B 胜出，也不能仅凭本实验推出所有语义都在 backbone、
head 完全不做语义计算，或生成训练从零必然得到统一语义空间。

## 事后解释性补充：扰动误差中的平移与变形

完整扰动结果中，Show-o2 生成槽位更换固定噪声出现大坐标误差，但关系
指标基本保留。为解释这一差异，新增 CPU-only 残差分解，覆盖四个已有
受扰设置，在 COCO512 固定子集上检查共同均值／原生任务位置、固定32／
源 dev 选择，共 48 条；不改变任何正式设置、噪声或已报告成绩。

用原始特征和原冻结均值／PCA／RMS／Q 独立重算原始及扰动后的残差。
平方误差严格拆成样本数乘平均残差平方与中心化残差平方和；两者变化量
之和必须等于原误差变化。同时描述原始表示变化中整体平移的能量比例。
这一步使用测试均值作误差描述，**不将它用于重定位预测或提高分数**，
不把事后解释当成目标适配后的成功，也没有在测试集重新拟合映射。

执行入口 `scripts/explain_geometry_v5_perturbations.py`，结果为
`audits/perturbation-error-decomposition.json`，原始 48 条误差变化全部
重现。恒定平移／中心化缩放的代数分别有单元测试。绘图为显示全部量级，
仅当某面板置信区间绝对值超过20时使用明确标注的 symlog 横轴；[-1,1]
内保持线性，原线性轴版本也保留，没有裁剪大负值。
