# B 的跨模态语义：V2 实验设计

日期：2026-09-07。状态：冻结模型阶段已执行，见 [V2 结果报告](B_SEMANTIC_EMERGENCE_V2_RESULTS_20260907.md)。已完成 Content / query / mask 控制及初始化参考；新增训练和 head 生成因果干预未执行，开发机已停止。下文保留原设计范围，不表示所有强化项均已完成；实际覆盖与限制以结果报告为准。

本文重新界定 [V1 表征实验](B_REPRESENTATION_PROBE_20260907.md) 能回答的问题，并给出可区分表征、读出、训练来源和生成用途的实验。保留 V1 的原始结果，不将新的分析设计追溯声明为 V1 的预注册协议。

## 1. 要检验的命题

主命题：在预训练 Qwen 与 VAE 的基础上，不引入显式对比、类别分类或特征对齐损失，图文条件生成训练是否进一步建立了可跨模态复用的语义结构？

这里“纯生成/重建类目标”不等于无配对监督，也不等于随机初始化。B 的实际运行配置包括：

- 文本交叉熵、图像 flow matching 目标；不是同一个字面意义上的像素重建损失。
- `climbmix, t2i, climbmix, i2t` 混合训练，T2I/I2T 使用图文配对。
- `Qwen3-0.6B-Base` 初始化，预训练 MAR KL16 VAE 提供 latent，`from_scratch: false`。
- 图像 flow head 有 8 层、宽度 1280，并接收 backbone XT query 与 X0 content 两条条件路径。

实际配置来源：[run config](../output/unified-b-x0content-0p6b-100b-imagenet-split-s42-r1/config.yaml)。运行配置优先于通用消融协议的默认值。

需要区分四个强度不同的问题：

| 问题 | 所需证据 | 不能用什么替代 |
| --- | --- | --- |
| 各模态含有语义信息吗？ | 域内语义探针、语义保持/改变对照 | 重建质量或类名模板的高分类率 |
| 图文共享部分语义结构吗？ | 无映射跨模态检索、跨模态探针、关系结构一致性 | 单一共有文本 query 的分数 |
| 共享结构是此次训练建立或增强的吗？ | 可信初始化参考、训练时间轴、匹配训练对照 | 最终 checkpoint 的层深曲线 |
| 原生生成过程实际使用这些共享信息吗？ | 固定 head 的语义干预与条件路径控制 | backbone 上训练一个新分类器 |

“所有语义只在 backbone，head 仅做采样”不作为二元可直接证实的主命题。改为检验：backbone 是否提供可跨模态复用、且被两个原生 head 使用的语义条件。

## 2. V1 保留什么、不能推出什么

V1 的 Query 是：图像输入和文本输入后，均追加共同文本后缀，再读取同一种文本 query。图像输入没有读取配对 caption，因此这不是图文标签泄漏；它是一个有效但特定的共同读出实验。

原生 query 的初始化则不同：文本 `<|mdm_mask|>` 为 151669，图像 `<|img_mask|>` 为 151672。二者位于同一 embedding 表的不同行，不绑定参数。见 [query 初始化](../models/modeling_model/modeling_selfless_flow.py#L1287)。

不同 mask 不只是可能带来均值偏移：query 进入 Q 投影和 attention，因此可能改变对上下文的读取。减均值不能替代对 query 身份的控制。

V1 的 Content mean 不通过末尾 query 汇聚信息，因此不受该末尾 query 身份的直接影响；但仍有任务前缀、token 汇聚与上下文覆盖等因素。它应成为 V2 的主要表征检验，而不是被一并否定。

## 3. 实验 A：不依赖共有文本读出的 Content 语义

### 输入与采集

- 图像与文本独立前向，绝不在同一次表征提取中放入其配对另一模态。
- 主条件移除 V1 的描述任务前缀与语义后缀，只保留处理格式所需的边界 token；不含类名提示。
- 无任务提示的输入可能不同于训练分布。因此必须平行报告原生训练提示和固定中性提示控制；任何单一提示条件的失败都不能直接解释为“无语义”。
- 保持 B 原生 content 对角线可见、query 严格 sigma 因果规则。不为提分临时改为全双向 attention。
- 主读出为正文/图像 latent token 的 X0 mean，排除边界、提示、padding。
- 辅助读出为数据 token 中 sigma 最大位置的 X0。它能够访问本样本全部先前数据与自身，用于检查平均汇聚及上下文覆盖造成的差异；报告位置/末 token 偏置，不在测试集选最优汇聚。
- 记录入口、28 个 block 输出、最终 RMSNorm；固定三组 image sigma seed。后验均值作为一种确定性控制，与固定后验采样分开报告。

### 指标分级

1. **直接坐标对齐**：原始余弦、模态中心化余弦的双向检索，以及相同语义标签的跨模态线性分类器迁移。中心化不包含学习旋转。
2. **关系结构共享**：以独立编码的对应场景或类别为索引，分别构建图像内部、文本内部的关系矩阵，比较其结构，而不要求两个空间坐标逐维相同。报告线性 CKA、去对角元素的距离秩相关，并使用整体与类内打乱对应关系的零分布。
3. **可学习的线性可对应性**：仅在拟合集学习正交 Procrustes/固定正则 ridge 映射，在独立图像和独立类别上测试。必须与同容量打乱配对拟合比较。只在这一项成功时，结论是“可经学习映射对应”，不是“原生直接对齐”。

关系矩阵的比较参考 [Kornblith et al., ICML 2019](https://proceedings.mlr.press/v97/kornblith19a.html)。CKA 不单独作为语义证据：相似性也可能由低层视觉属性、长度或其他共同变量驱动；必须配合下面的语义控制。

### 真正的语义控制

- 同类不同图像、同一内容的不同表述应保持关联，而非只认出同一图像的五条 caption。
- 分开测对象类别、属性、数量、关系，报告各子任务，不将对象类别识别等同于全部语义。
- 困难负例优先保持名词与长度相近，仅改变颜色、数量或关系；必须确认负例与图像实际不符，避免把另一条正确描述误作负例。
- 拟合前固定模板组和样本组；不得把同图的多条 caption 或同一词面模板的变体跨越拟合/测试边界。
- 学习映射时另做类别不相交测试；同类别的跨模态分类器迁移不能替代对新类别的泛化。
- VAE latent 的同口径视觉探针作为低层信息参考，不把输入图像已有语义都归于 B。

## 4. 实验 B：将原生 query 与 mask 身份效应分开

### B1. 原生条件预测状态

分别采集：

- I2T：只给图像上下文，读取首个目标文本位置的文本 query，不喂入真实目标 caption。
- T2I：只给文本上下文，读取 sigma 中首个目标图像位置的图像 query，不喂入真实目标图像；对固定多组首位置采样分开报告。

这些是不同生成任务下对输入场景的条件状态，不是某个已观察 token 的内容表示。先比较对同一组场景/类别/属性的可读性与关系结构，再描述其直接距离。不得逐位置配对 caption token 和图像 patch，或将直接距离失败当作没有共享语义。

第一目标位置用于避免真实目标前缀带来的语义泄漏；它本身的任务/空间粒度仍不同。因此结果不能单独归因于 mask token。

### B2. 只替换初始 query 向量的配对干预

对每个固定上下文、固定 query 槽位，保持 X0、token types、位置编码、attention 可见集合和所有权重不变，仅替换该槽位的初始 XT 向量：

| 上下文 | 注入文本 mask embedding | 注入图像 mask embedding |
| --- | --- | --- |
| 图像 | I / text-mask | I / image-mask |
| 文本 | T / text-mask | T / image-mask |

在每种原生槽位上分别执行这一控制。不能通过改变 `token_types` 实现“换 mask”，因为那也会改变位置/模态路径。

跨 mask 的单因素替换是诊断性的、可能分布外的干预，不称为“原生图像 query”。报告原生槽位结果与干预结果，不混合汇总。

除了分别中心化的分数，还要比较同样本更换 mask 造成的变化，与跨样本语义差异的变化。几何分析可分别估计上下文模态 × query 身份 × 槽位的拟合均值；同时保留只按上下文模态中心化版本，避免中心化操作掩盖 mask 身份效应。

实现验收：只替换 XT 后，每层 X0 应在确定性执行下逐元素不变；隐藏目标占位替换不能影响已定义的读出。Backbone 的 K/V 来自 X0，见 [attention 实现](../models/modeling_model/modeling_selfless_flow.py#L739)。

## 5. 实验 C：语义是否由本次训练建立/增强

已核实该 run 顶层当前保留 `checkpoint-92000`、`checkpoint-94000`、`checkpoint-95415`、最终 raw/EMA 导出。实际 `save_ema_eval_every` 为 0，不能依据通用协议中的默认设置假定早期 EMA 存在。

- 先检查有无其他可信归档；没有权重的早期 loss 日志不能用于补造表征曲线。
- 初始化参考必须是完整 B 初始化流程：相同预训练 Qwen/VAE、特殊 token 扩展、projector/head 初始化与配置。单独拿原版 Qwen 或随机 projector 不足以替代完整初始化。
- 只有初始化工件或可验证的随机状态/参数一致性，才能称“该 run 的准确 step 0”。仅按 seed 42 重新构造应标为“初始化流程参考”，必要时报告多个初始化种子。
- 最终 raw 对 raw、EMA 对 EMA 单独比较；不得把权重平均方式差异描述为训练语义变化。
- 初始化参考与最终 B 的差异可支持本次训练后的增量，但仅凭两个时间点不能定位“涌现发生在第几步”。

若需要训练因果结论，另行设立短程、同预算的受控训练，而不是未经确认启动新的 100B 训练：

| 训练臂 | 改变因素 | 主要用途 |
| --- | --- | --- |
| 配对生成目标、全量训练 | 基准 | 观察共享结构随更新变化 |
| 同样数据边际分布、每步打乱跨模态条件对应 | 图文条件关联 | 检查配对关系的贡献 |
| 配对生成目标、冻结预训练 backbone | 是否更新 backbone | 区分适配器接入已有语言结构与 backbone 自身更新 |

对照保持初始化工件、数据量、source schedule、目标定义和评测样本一致，报告生成损失与域内能力。打乱配对会改变条件问题的可预测性，因此性能下降不能直接归因于“对齐机制被单独删除”。可补充移除跨模态条件的生成臂，区分错误条件的干扰与缺少条件。

所有对照保存真实 step 0 与早期权重，至少三个训练种子。若要声称随机初始化也会出现同一现象，还需随机 backbone 对照；它是更强、成本更高的问题，不是对现有 B 的默认结论。

## 6. 实验 D：共享语义是否被原生 head 使用

这是继 A/B 之后的独立实验，不以检索分数替代。

- 冻结原生 backbone、LM head、flow head。在独立拟合集确定共享类别/属性方向或低秩子空间，不使用最终测试生成结果选择方向。
- 对文本与图像两类原生生成状态，分别实施该语义分量的移除、受控替换或小幅定向变化，观察输出的同一语义属性是否按预期变化。
- 对照为同维数/同扰动范数的随机子空间、无操作、同语义样本替换、不同语义替换；同时测非目标属性与总体质量，排除普遍破坏激活造成的假因果。
- 跨模态替换不得直接把整条文本状态硬塞到任意图像 patch 位置。只操作预先定义的语义部分，保留接收方位置、模态特有残差、尺度与正确的均值恢复；即使如此也报告其分布外风险。
- Flow 需要分别控制 XT query 和 X0 content 条件，再联合控制；只改 query 而保留 content 中完整语义不能称为“去掉 backbone 语义”。
- 审计 flow 的真实 latent/context/cache 等所有旁路。主生成从纯噪声开始、固定噪声与生成顺序，不允许接收方仍读取被替换语义的真实目标图像。带真实目标的低噪声 flow loss 不能充当此主证据。
- 条件对齐、空间接口与目标可见性不满足时，记录为实验不可解释，而不是用失败分数否定共享语义。

成功只能支持“这些 backbone 语义分量被原生生成利用”，仍不能证明 head 内不存在进一步的语义计算。

## 7. 统计与实施顺序

- 模态均值只在独立无标签校准集估计，然后冻结到测试集。主检索统一为先减均值、再 L2 归一化；分类器输入预处理另行固定并记录，不混用 V1 的不同处理顺序。
- 校准、映射拟合、超参数/层选择、最终测试按图像 ID 分组隔离；学习映射的类别外推另设类别隔离。相同图像的五条 caption 是一个统计组。
- V1 的 Flickr test 和 27 层峰值已经被查看。复用它们的 V2 结果属于后续诊断，不能宣称新的独立确认性测试。确认性测试需冻结协议后使用未参与 V1 分析的新样本/数据划分，并核查缓存可用性；没有新数据时明确保留探索性标签。
- 报告全部层曲线与预先固定的最终层结果。若需要选择单层，只在开发集选择，再在新测试集评估。
- 检索报告双向 R@1/5/10、按图分组 bootstrap 与配对随机化对照；CKA/关系指标报告对应关系打乱的零分布。做层间显著性声明时校正多重比较，不从几十条曲线中只挑有利结果。
- 接受“不直接对齐但关系结构相近”“仅共同文本读出有效”“初始化已存在大部分结构”等结果，不将任何单一指标定义成必然成功。

优先执行 A + B，并补可信初始化参考；这不需要更新模型。C 的新增训练、D 的完整生成干预分别立项和限定资源，不属于本设计稿已经启动的工作。

V1 原始数值继续有效，其结论范围保持为：最终 B 在特定汇聚/读出协议下存在跨模态关联。V2 才用于区分这种关联是否跨提示、跨原生 query 稳定，以及如何归因于训练与生成机制。
