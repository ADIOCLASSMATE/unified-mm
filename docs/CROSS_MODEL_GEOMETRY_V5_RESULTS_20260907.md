# 跨模型逐层语义几何 V5：结果与判断

实验范围：B、F、JanusFlow、Show-o2、SigLIP、DINOv2＋原始 Qwen、
MAE＋原始 Qwen 七组比较；14 个路径／提示设置、41 条读出曲线、1171 个
层对×读出组合，全部保留。计算与统计覆盖的证据见文末审计入口。

## 核心问题：不是“向量是否相似”，而是“关系是否可对应”

这次实验区分三层证据：不拟合跨模态映射的 kNN／RSA／CKA；只用源域
fit 数据学习的正交映射在留出类别或场景上的误差；冻结所有参数跨域和
分辨 ARO 困难负例的能力。它们不能互相替代。

已有证据支持 B 存在共享关系结构和部分可泛化的低维对应，但不支持把
两侧称为全空间严格同构，也不支持“这种现象只有 B 才有”。B 相对 F 的
优势取决于读出、层和迁移方向；即使关系结构更强，也不能据此证明
flow head／LM head 完全不做语义计算。

一个特别贴近最初直觉的结果是：Show-o2 更换生成噪声时，原生生成槽位
会发生很大的整体坐标平移，但关系结构基本保留。因此，坐标误差、
关系结构和语义功能确实需要分开检验，不能只选其中一个指标下结论。

数值、条件置信区间和所有读出详见
[完整机器数值报告](../output/evaluation/research/cross-model-geometry-v5-20260907/RESULTS_ZH.md)，
方法边界见[方法文档](CROSS_MODEL_GEOMETRY_V5_METHODS_20260907.md)，
命令见[复现入口](CROSS_MODEL_GEOMETRY_V5_REPRODUCE.md)。

## 1. 比较口径

沿用 [V4](B_GEOMETRY_PROTOCOL_V4.md) 和
[V5](CROSS_MODEL_GEOMETRY_PROTOCOL_V5.md)：ImageNet 32000 图、12000 条
模板，600／200／200 个映射 fit／dev／test 类别；COCO 11776 场景、58909
条 caption，512／8192／1024／2048 个 cal／fit／dev／test 场景。同一场景
先平均原始 caption 特征，不把多条 caption 当成独立测试图像。

几何曲线使用 200 个 ImageNet 测试类别或固定 512 个 COCO 测试场景；
映射误差使用全部 2048 个 COCO 测试场景。ARO 使用 451 属性＋417 关系，
共 868 张已核对 COCO ID 与本次全部 COCO 划分互斥的原图；不在 ARO
拟合或选择任何参数。这不等于图像内容去重或预训练语料去污染。

ImageNet 的“新类别”仅相对拟合 Q，B/F 的训练已经使用这些类别。
COCO 是相对 B/F 本次 ImageNet 多模态训练的图像域外数据，不能宣称它
对所有外部模型、语言模型和 VAE 的预训练都严格域外。

主对照是固定最终 norm、共同 content_mean、欧氏模式、32 维；
128／512 维、单位球、其他读出、所有实际层和 dev 选层都保留。
每侧独立 PCA、均值、整体 RMS 单位及 Q 只来自源域，Q 允许旋转／反射，
不做逐轴白化或一般线性拉伸；跨域不重新中心化或拟合。
full 仅用于原始宽度相同的模型自身诊断，不混入共同预算主排名。

不同深度模型按预先冻结的相对深度网格比较，保存真实图／文层号；最后
一个 block 和最终 norm 是两个不同位置。显式对齐过的 SigLIP pooler
单列，不能把它当成未经训练的通用均值池化。

## 2. B 有关系结构，但这不是其独有属性

固定最终层共同内容均值，B 的 ImageNet CKA／RSA／kNN@10 为
0.597／0.337／0.2475，COCO 为 0.373／0.164／0.182。模态均值已分别处理，
仍有关系对应；但不同指标测的是不同性质，不能把 CKA 值读成语义正确率。

独立的 DINOv2＋原始 Qwen 在 COCO 上分别为 0.632／0.371／0.310，
其 32 维留出旋转 R² 为 0.290。两者没有本次新训练的图文连接器，
也仍能出现这种结构对应；拟合 Q 用了配对数据，因此这不是未经拟合的
零样本坐标对齐。它说明“存在对应结构”不足以构成 B 的独特优势。

MAE＋Qwen 的最终层共同均值较弱，COCO CKA 为 0.086、旋转 R² 为
-0.569；源域 dev 选到最后一个 block 后，留出 R² 改善到 -0.182，
仍不能据此声称仅靠视觉重建目标必然得到可旋转的共同空间。
这也不是对所有 MAE 表征、读出或预训练预算的否定。

输入位置也不能默认没有语义：JanusFlow 理解路径在 COCO 的输入 CKA
已约 0.628，最终约 0.705。上游 SigLIP 已提供语义。B 的输入到最终层
CKA 约从 0.238→0.597（ImageNet）、0.189→0.373（COCO），但这只是
层间表征变化，不是排除了 Qwen／VAE 初始化贡献的从零涌现证明。

## 3. 严格留出旋转和跨域迁移

下表是固定最终层、共同内容均值、欧氏 32 维的 R² 点估计；
完整报告保留全部 95% 区间、打乱拟合对照和方差覆盖。各模型 R² 的
分母属于自己的表示空间，并非同一像素或文本重建目标的误差。

| 模型／路径 | IN→IN | IN→COCO | COCO→COCO | COCO→IN |
| --- | --- | --- | --- | --- |
| B | 0.128 | -0.913 | -0.005 | 0.193 |
| F | -0.003 | -1.059 | -0.176 | -0.006 |
| DINOv2＋Qwen | 0.171 | 0.035 | 0.290 | -0.040 |
| MAE＋Qwen | -0.566 | -1.068 | -0.569 | -0.094 |
| SigLIP 内容均值 | 0.330 | -0.386 | 0.327 | 0.020 |
| JanusFlow 理解 | 0.307 | 0.099 | 0.461 | 0.070 |
| JanusFlow 生成 | -0.209 | -1.219 | -0.317 | -0.171 |
| Show-o2 理解 | 0.204 | -0.077 | 0.307 | 0.066 |
| Show-o2 生成 | 0.201 | -0.121 | 0.317 | 0.059 |
| SigLIP 原生 pooler（另列参考） | 0.526 | -0.277 | 0.357 | 0.016 |

负 R² 保留其本意：该受约束映射未优于预测源域拟合目标均值；它不等于
完全没有语义。如果仍明显优于打乱拟合，说明配对关系有信息，但不能把
这种相对改善夸大成准确同构。B 的 COCO 留出区间 [-0.033, 0.025]
跨过 0，ImageNet→COCO 则明确为负。域内或某一个迁移方向的成功，不是
两个域间普遍可转移的等距空间。

低维结果还必须结合覆盖率：B 的 ImageNet32 映射在测试图／文两侧保留
约 0.807／0.393 方差，COCO32 约 0.691／0.752。成功或失败仅涉及声明
的子空间，不能替代完整表示信息量的判断。full 在样本不足、跨协方差
低秩或病态时不构成可识别的全空间旋转证据。

源域 dev 最优也未必跨域最优。例如 Show-o2 理解的 COCO 内容均值，
dev 选 block26/d32 后留出 R² 从 0.307 提高到 0.396，而冻结迁移到
ImageNet 从 0.066 变为 -0.289。这是必须保留的泛化落差，不能回看
ImageNet 成绩再重选“跨域最好层”。

正式配对区间显示：在这一预定主口径下，B 的四个方向均高于 F、
MAE＋Qwen 和 JanusFlow 生成的内容均值；COCO 留出则低于 DINOv2、
SigLIP、JanusFlow 理解与 Show-o2 两条路径。ImageNet 留出中 B 与
Show-o2 两条路径的差值区间都跨 0，不宣称显著胜负。
COCO→ImageNet 的 B 分数高于八个共同均值参照，配对区间均为正；
但这个目标域正是 B/F 多模态训练的 ImageNet，不能把优势推广为任意域外
泛化。以上均是预定口径的逐项条件区间，不是对所有读出或模型机制的排名。

## 4. B 对 F：优势成立的范围

两者的实际 dataset、optimizer、scheduler、training 配置逐字段相同，
最终 EMA 都为 step95415，flow head 参数量相差约 0.149%。F 使用自己的
`PositionwiseFlowOnBQwen3ForCausalLM`，没有用 B 类加载代替；F 移除了
head 跨 token 交互，但不是移除了 head 的一切语义计算。两者分别训练，
不是共用同一组 backbone 权重，也没有多个独立训练种子。

预定主对照中，B−F 的配对 ΔR²：

| 来源→目标 | ΔR² | 条件 95% CI |
| --- | --- | --- |
| ImageNet→ImageNet | 0.131 | [0.071, 0.193] |
| ImageNet→COCO | 0.146 | [0.116, 0.175] |
| COCO→COCO | 0.171 | [0.155, 0.187] |
| COCO→ImageNet | 0.199 | [0.171, 0.226] |

这些是同一测试身份上的配对差值，不是目测两条独立区间。
但在 COCO 源域各自 dev 选层后的原生 query 读出，B 选 block14/d32，
F 选 block22/d32，全部 COCO 留出场景的 R² 为 0.28739／0.28772；
差值 -0.00033 的区间 [-0.03700, 0.03602] 不支持二者有明确差异。
同一映射迁移到 ImageNet 则为 0.500／0.252，B 的配对差值区间
[0.225, 0.272] 为正。因此“B 的 backbone 在所有层、读出和任务都更语义化”
不是本实验支持的结论。

这里的文本／图像 query 也不是同一个 mask：ID 分别是 151669／151672。
native 两侧本来就是不同的任务位置；bare／neutral 曲线和精度警告另存，
不能把异构 query 当作同质内容 embedding 来解释。

## 5. Flow 模型：生成槽位与内容 token 必须分开

探针只读取 backbone，不执行完整生成采样。图像条件为 clean VAE
posterior mean、t=1、空文本；文本条件为观察文本、t=0、对所有样本相同
且不含语义身份信息的高斯噪声。不把配对真图送进“文本表征”。
因此测的是明确任务／时间条件下的空间，而非宣称时间无关的统一表示。

JanusFlow 的生成内容均值在 COCO 留出旋转上较弱（-0.317），但生成
槽位均值的源域 dev 选择为 block6/d32，留出 R²=0.377，冻结
COCO→ImageNet 为 0.465。其 ImageNet 源域的相同读出也选 block6。
这恰好是论文施加 REPA 的层；值得作为机制线索讨论，但不是消融实验，
不能独立建立因果关系。[JanusFlow 原论文 §3.4、§4.1](https://arxiv.org/html/2411.07975v1)

JanusFlow 的因果注意力使前面的内容 token 看不到后面的生成噪声，
所以内容均值对噪声种子几乎不变，不是非平凡的生成语义鲁棒性证据。
生成槽位才直接检验噪声影响。在预定 COCO512 子集，block6/d32 的两个
额外种子同分母误差变化分别约 -0.0004 和 +0.0088，图像 t=0.5 为
-0.077（区间 [-0.095, -0.060]）。不因某个种子更好而替换主种子。

Show-o2 生成内容均值在 COCO 源 dev 选 block26/d32，留出 R²=0.399，
COCO→ImageNet=-0.106；原生生成槽位均值选 block6/d32，分别为
0.116／0.056。不能把两者或理解路径的分数混在同一语义读出结论里。

Show-o2 的固定映射对噪声／时间坐标特别敏感。COCO512 鲁棒子集、
上述 block6/d32 生成槽位均值，额外 seed1／seed2 的同分母误差变化
分别为 -95.317／-111.800，但 CKA 从约 0.449 变为 0.463／0.463，
kNN@10 也基本保留。这不是“所有语义消失”。

为解释这一异常量级，追加了明确标为**事后解释性**的残差分解，覆盖
B、F、JanusFlow 和 Show-o2 的共同均值／原生任务位置、固定32／各自
dev 选择，共 48 个 COCO 扰动条件。它从原始特征和冻结映射独立重算误差，
不拟合新 Q、不改变预测、不用目标均值提高成绩：

- Show-o2 生成槽位 seed1／seed2 的原始变化能量，99.99996%／99.99973%
  来自整体平移；误差增加也几乎全部是平均残差项，中心化残差项没有同等
  恶化。因而固定坐标映射失败和关系结构保留可以同时成立。
- 图像 t=0.5 的 block26 内容均值则不仅有平移：CKA 约从 0.664 降至
  0.082，中心化变形 RMS 约为原语义变化的 2.48 倍。其大误差不能全解释
  成“只是换了原点”。

证据见[残差分解](../output/evaluation/research/cross-model-geometry-v5-20260907/audits/perturbation-error-decomposition.json)。
这不是目标域重新中心化后的新主成绩，也不是噪声鲁棒性的因果结论。

B/F 的 sigma 干预还改变首图像 query 的空间位置，不能全归因于顺序。
例如 COCO dev 选层的 B 原生 query，sigma2 的同分母误差变化为
-0.337 [-0.370, -0.306]，而内容均值约 +0.004、区间跨 0。
这说明任务位置读出可能含较大的空间位置成分；不能仅减去一个模态均值
就假设它变成位置无关的纯语义。后验均值控制的影响远小于这一变化。

## 6. 困难负例不能只看是否超过 50%

固定最终层、欧氏32、COCO8192 映射，B 的 ARO 余弦正确率为属性
54.5%、关系 56.1%，相对任务内打乱图像的增益区间都跨 0。
距离读出的关系增益约 7.4 个百分点，区间 [1.9, 12.9] 个百分点，
但正确率本身只有 48.9%；打乱基线更低，说明不能只用 50% 作唯一参照。
它是局部功能证据，不足以声称稳定的组合语义优势。

SigLIP 原生 pooler 的属性余弦正确率约 63.4%，相对打乱图像的增益
区间约 [6.0, 19.5] 个百分点；其与共同均值、B 以及其他模型的全部
结果均另列。ARO 不用于选层、选维度或选择“最有利”的相似性函数。
所有置信区间都是逐项、条件于当前权重和拟合，不是整个实验的同时区间。

## 7. 能归因于什么，不能归因于什么

| 比较组 | 实际载入参数范围（约） | 语义来源和关键差别 |
| --- | --- | --- |
| B／F | 各 0.761B，不含 MAR VAE | Qwen Base、MAR VAE 初始化；ClimbMix＋配对 ImageNet 条件生成；文本 CE＋图像 flow |
| DINOv2＋Qwen | 0.087B＋0.596B | 独立单模态；DINOv2 小模型含自监督教师蒸馏 |

| SigLIP | 两塔合计 0.878B | 显式成对图文 sigmoid 对齐；原生 pooler 训练过 |
| JanusFlow | 2.046B，另载 VAE 0.084B | SigLIP 理解编码器＋REPA；AR／rectified flow／SFT |
| Show-o2 | 去重复共享存储后 2.831B，另载 VAE 0.127B | Qwen2.5-Instruct、SigLIP 蒸馏语义路径、Wan VAE、AR／flow 与指令数据 |

参数核验、已下载资产的精确 revision、代码快照和 B/F 全配置差异见
[来源审计](../output/evaluation/research/cross-model-geometry-v5-20260907/audits/model-sources-and-training.json)。
原始 Qwen Base 来自已有本地权重；不补写没有记录的上游 revision。
Show-o2 的 1.5B 名称不是整个模型参数量，其 embedding／lm_head 共享
存储不能重复计数。[Show-o2 原论文](https://arxiv.org/html/2506.15564v2)
描述了 SigLIP 蒸馏和两阶段训练；不能把它或含 REPA 的 JanusFlow 称作
仅用无教师重建损失的基线。

B/F 的本次统一训练虽没有新增 CLIP／REPA 表示对齐项，但不等于
“从零无语义”：文本模型和 VAE 已预训练，ImageNet 条件文本与图像又有
明确配对关系。因此，本轮回答的是这些固定权重中有哪些关系结构和
可转移子空间，而不是证明压缩目标一般地必然涌现统一语义。

各模型预训练数据、教师、规模、指令训练不同，且外部图像均先采用与
B 相同的 Resize256／CenterCrop256 内容视图再适配原生分辨率。
这里不是各模型最优原生推理榜单，不能从排名直接归因于架构或计算效率。

## 8. 数值、复现与完成审计

只读原始权重，所有前向冻结，无新增训练。权重、官方源码和隔离依赖
写入 public/models，下载显式禁用代理；精确参数加载、字节数、文件格式、

FP32 计算，Show-o2 进一步用 FP32 存储与稳定的输入均值计算。修订依据
只来自 cal，Show-o2 在语义得分计算前重提全部特征，旧完整产物归档保留。
